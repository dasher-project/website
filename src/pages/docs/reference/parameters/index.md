# Parameters Reference

<nav class="breadcrumbs">
  <a href="/docs/reference/">← Back to Reference</a>
</nav>

Dasher can be configured through various parameters to customize the experience for your needs and preferences.

## Common Parameters

### Speed Settings

- **Bitrate** - Controls the maximum zoom speed. Higher values make Dasher zoom faster.
- **Frame rate** - How often Dasher updates the display (typically 30-60 FPS).

### Display Settings

- **Font size** - Size of the text display
- **Colors** - Color scheme for the Dasher interface
- **Show mouse position** - Display pointer location

### Input Settings

- **Input device** - Mouse, touchscreen, eyetracker, etc.
- **Control mode** - Standard, one-dimensional, or button mode

### Language Settings

- **Alphabet** - Choose from 60+ supported languages
- **Training file** - Path to training text for personalization
