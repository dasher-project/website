# Dasher Mobile: A New Android Implementation

<div class="blog-post">
  <header class="blog-header">
    <div class="blog-meta">
      <time datetime="2026-05-19">May 19, 2026</time>
      <span class="blog-tag">Community</span>

  </header>

  <div class="blog-content">
    <p>
      We're pleased to highlight <strong>Dasher Mobile</strong>, a new Android implementation of
      the Dasher text-entry system developed by Ján Murin as part of his bachelor's thesis at
      Masaryk University.
    </p>

    <h2>About the Project</h2>
    <p>
      Dasher Mobile builds on <a href="https://github.com/dasher-project/dasher" target="_blank" rel="noopener noreferrer">DasherCore</a>
      and extends it with <strong>KenLM language model integration</strong>, with a focus on
      Slovak language support. The result is a native Android app that brings Dasher's
      predictive zooming interface to mobile devices with improved language prediction.
    </p>

    <h2>Key Features</h2>
    <ul>
      <li><strong>Native Android app</strong> built on DasherCore</li>
      <li><strong>KenLM language models</strong> for improved text prediction</li>
      <li><strong>Slovak language support</strong> as a primary focus</li>
      <li>Touch-based input using Dasher's continuous zooming interface</li>
    </ul>

    <h2>User Testing</h2>
    <p>
      The project is currently in a user testing phase where participants complete twelve
      5-minute text transcription sessions. The goal is to evaluate typing speed, error rate,
      and learning curve, providing valuable research data on Dasher's usability on mobile
      devices.
    </p>

    <h2>Try It</h2>
    <p>
      The latest release (v1.0 APK) is available for download. The project is open source
      and contributions are welcome.
    </p>

    <p>

      implementation that addresses a specific language community's needs.
